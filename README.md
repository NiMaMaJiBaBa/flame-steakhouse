## 💻 如何啟動與瀏覽

本專案經過純淨架構設計，**無需複雜的 npm 套件安裝，開箱即用**：

### 方法一：直接使用瀏覽器開啟（最快速）
直接雙擊進入 `flame-steakhouse` 資料夾中的 `index.html`，即可在任何現代瀏覽器（Chrome、Edge、Safari、Firefox）中完整瀏覽所有內容與互動功能！

### 方法二：使用 Python 本機伺服器（推薦）
在 Windows 系統中，直接**雙擊 `start_server.bat`** 腳本：
1. 程式會自動啟動本地 Web 伺服器（預設 Port `8080`）。
2. 自動在您的預設瀏覽器中開啟 `http://localhost:8080/`。
3. 若需停止伺服器，直接關閉命令提示字元視窗即可。

## 🎨 採用技術

- **HTML5 & Vanilla JavaScript (ES6+)**：保證在任何設備與環境中極速載入、穩定無依賴。
- **Tailwind CSS 3 (CDN)**：現代化原子化樣式，精準掌控色彩、間距與排版。
- **Lucide Icons**：現代簡約向量圖標庫。
- **Google Fonts**：繁體中文《Noto Serif TC》（思源宋體）、《Noto Sans TC》（思源黑體）與英文典雅字體《Cinzel》。
- **LocalStorage API**：客端預約訂位資料本機快取與即時管理。
